# Calculadora Web

Proyecto desarrollado con HTML, CSS y JavaScript.

## Funcionalidades
- Suma
- Resta
- Multiplicación
- División
- Limpieza de pantalla

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Cómo ejecutar
1. Descargar el proyecto.
2. Abrir el archivo `index.html` en cualquier navegador.
